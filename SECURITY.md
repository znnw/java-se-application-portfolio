# Security Policy

## Scope

This repository is an educational and portfolio project. The latest commit on
`main` is the supported version.

The chat system uses a plaintext custom protocol and is intended for trusted
local networks. The employee login uses in-memory demo data and is not an
authentication implementation for production use.

## Reporting a Vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use the repository's **Security** tab and select **Report a vulnerability** to
open a private security advisory. Include:

- the affected module and entry point;
- reproduction steps;
- expected and observed behavior;
- the potential impact;
- any suggested mitigation.

Reports will be reviewed before public disclosure.
